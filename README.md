# Individual Player Timer

A Paper plugin for Minecraft servers that gives each player an individual countup or countdown timer.

## Current features

- Per-player timer storage
- Countup mode
- Countdown mode
- Actionbar display
- `/playertimer start`
- `/playertimer start countup`
- `/playertimer start countdown <seconds>`
- `/playertimer stop`
- `/playertimer reset`

## Target

Built initially for Paper servers.
